# Torre Ejemplo

Maqueta de seguimiento de una inversión en pozo. La obra, la constructora y los esquemas de la cámara son ficticios.

El cronograma compara lo prometido en el boleto con lo observado en las fotos. El estado de cada hito lo calcula una regla. El chat, por ahora, responde solo las cuatro preguntas de la demo. La foto que se sube se ve en la cámara y todavía no se analiza.

## Correr

```bash
npm install
npm run dev
```
